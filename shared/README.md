# Shared contracts

Owner: Person 3. All shared data shapes, validation rules, status values, API contracts, database files, and reusable itinerary grouping logic belong here. Person 3 also owns `docs/` and root project files.

`contracts/` is reserved for interfaces used by the frontend and backend. `database/schema.js` and `utils/itinerary.js` are empty placeholders. Agree on changes to shared contracts before dependent frontend or backend work is merged.

Key concepts include trips, members, imports, places, evidence, reactions, concerns, and day assignments.
