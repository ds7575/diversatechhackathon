# Group Travel Planner

An iPhone-first group travel planning prototype for turning shared Instagram Reels into researched place ideas and an editable day-by-day plan.

This repository currently contains project structure and planning documents only. No application code or framework has been selected yet.

## Repository structure

```text
apps/
  web/       Mobile web experience
  api/       API and background processing
packages/
  shared/    Shared data contracts and validation rules
database/    Schema, migrations, and seed data
docs/        Product, architecture, and delivery notes
```

## Prototype boundaries

The first prototype targets groups of 3–8 people and approximately 20–30 public Instagram Reels. It should support trip creation, member preferences, Reel capture, researched place cards, reactions and concerns, rough day planning, and collaborative edits.

See [docs/product-scope.md](docs/product-scope.md) and [docs/architecture.md](docs/architecture.md) before implementation.

## Getting started

There are no dependencies or services to install yet. Choose the implementation stack, document required environment variables in `.env.example`, and add setup commands here before writing application code.
